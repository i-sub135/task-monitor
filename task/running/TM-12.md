# TM-12 — Tambah field platform di Task

**Type**: feature
**Status**: Running
**Source**: perintah Iyan lewat DM, 2026-09-28
**Butuh**: TM-4 (form Task baru), TM-5 (halaman detail)

## Yang dibikin

Task belum punya penanda platform mana yang kena. Tiket ini nambah field `platform` di `Task`, dengan enum baru di level app (`src/lib/tasks.ts`, pola sama kayak `TaskType`/`Status`) dan di schema (`prisma/schema.prisma`, pola sama kayak `TaskType`):

- **Enum**: `API`, `Mobile`, `AI Chat` (persis perintah Iyan — key internal buat `AI Chat` kemungkinan `ai_chat` dengan `@map("ai-chat")`, ikut konvensi enum lain di schema ini, mis. `TaskStatus.in_progress @map("in-progress")`).
- **Migration**: kolom baru di tabel `task`, `ALTER TYPE`/`CREATE TYPE` buat enum-nya.
- **Form Task baru** (`task/new`): field pilihan platform, di samping Type (bug/feature) yang udah ada.
- **Tampilan**: minimal di halaman detail (`task/[id]`); board card dan filter belum tentu perlu (lihat "Belum diputusin").

## AC

1. Bikin Task baru: field platform kepilih (API/Mobile/AI Chat), tersimpan, dan muncul di halaman detail.
2. `npm run check` dan `npm run build` tetap lulus.
3. Task lama (dibuat sebelum tiket ini): kolom baru gak bikin app error atau task lama gak kebuka (nilai default atau nullable, tergantung keputusan di bawah).

Verifikasi manual (ikutin keputusan v1 TM-9: nol test otomatis, kecuali diputusin lain pas ngerjain).
