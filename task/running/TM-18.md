# TM-18 — Log aktivitas per token di /account/tokens

**Type**: feature
**Status**: Running
**Source**: perintah Iyan lewat DM, 2026-10-05 ("di /account/tokens itu kan sepi banget ya... bisa gak di tambah log aktifitas by token")
**Butuh**: TM-17 (token + jejak `via` di history/edit)

## Yang dibikin

Di bawah daftar token, section **Activity**: aksi terakhir yang dilakuin lewat token-token milik user itu.

- Satu baris = satu aksi: badge nama token, aksinya ("Created task", "Request → Queue", "Edited title"),
  judul task (link ke detail), waktu.
- Sumber data: `task_history` + `task_edit` yang `via`-nya keisi dan dibikin user itu. Gak ada tabel baru.
- Dropdown filter per token (default: semua token).
- 50 aksi terakhir.
- Token yang udah di-revoke: aktivitasnya tetep keliatan (namanya kecatet), ditandain "revoked".
- Cuma aksi nulis (create, edit, geser status). Baca (GET/list) gak dicatet ke DB, cukup di log app.

## AC

1. User yang pernah pakai token liat aktivitasnya di `/account/tokens`, urut terbaru di atas.
2. Filter per token jalan; aksi dari UI (tanpa token) gak ikut.
3. User cuma liat aktivitas token miliknya sendiri.
4. `npm run check` dan `npm run build` tetap lulus.
