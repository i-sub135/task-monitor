# TM-23 — Komentar di dalam task

**Type**: feature
**Status**: Running
**Source**: perintah Iyan lewat DM, 2026-10-07 ("fitur command di dalam task")
**Butuh**: TM-5 (halaman detail), TM-10 (rich text editor)

## Yang dibikin

Diskusi soal task bisa ditulis langsung di halaman detail task (kolom kiri, di bawah Attachments), bukan cuma
lewat catatan pas pindah status.

## AC

1. Di halaman detail (kolom kiri, di bawah Attachments) ada bagian **Comments**: daftar komentar (nama, waktu,
   isi) urut lama → baru, + editor rich text buat komentar baru (editor yang sama kayak description).
2. Semua user yang login boleh komentar.
3. Tulis/edit/hapus komentar boleh di semua status **kecuali Live dan Rejected**. Di dua status itu komentar
   tetep keliatan, read-only.
4. **Edit**: komentar yang pernah diedit nyimpen jejaknya (siapa, kapan, Before/After). Di komentarnya ada label
   "edited" yang dibuka buat liat jejaknya, tampilannya kayak Edit history description (Before dicoret, After).
   Semua user boleh edit/hapus komentar siapa aja.
5. **Hapus = hard delete**: komentar (dan jejak editnya) beneran dibuang dari DB. Konfirmasi pakai Dialog Skeleton.
6. Isi rich text disaring di server (aturan sama kayak description).
7. Kartu di board nampilin jumlah komentar (kayak 📎).
8. Gak ada lampiran di komentar (pakai Attachments task). API `/api/v1` gak ikut.
9. Server yang ngecek hak + status (bukan cuma UI ngumpetin form).
10. `npm run check` dan `npm run build` tetap lulus.
