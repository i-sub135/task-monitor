# TM-25 — Import task dari file JSON lewat UI (admin)

**Type**: feature
**Status**: Running
**Source**: perintah Iyan lewat DM, 2026-11-09 ("gw mau nambahin di fitur baru ni... upload data jeonnya..")
**Butuh**: TM-7 (admin), TM-10 (rich text), format `docs/task-import-format.md`

## Yang dibikin

Import task dari file JSON gak perlu lewat script + psql lagi. Admin upload file di `/task/import`, liat preview,
baru klik Import.

## AC

1. Halaman `/task/import` + link **Import** di navigasi, cuma buat **admin**. Role lain: halaman 403, action 403,
   link gak muncul.
2. Format + aturan validasi **sama persis** kayak script (`docs/task-import-format.md`): 5 field wajib, enum persis,
   tag HTML terbatas (mis. `<code>` ditolak), email huruf kecil. Satu modul (`src/lib/server/task-import.ts`) dipakai
   halaman dan `scripts/import-tasks.mjs`.
3. **Preview dulu, nol tulis**: jumlah task, daftar judul/type/platform/pembuat, deskripsi bisa dibuka, pembuat yang
   belum terdaftar ditandai "new user", task yang judul+platform-nya sama dengan yang udah di board (atau dobel di
   file itu sendiri) ditandai. Dobel cuma peringatan, gak ngeblok.
4. File gak valid = semua error ditampilin sekaligus (nyebut nomor task + tag yang salah), nol yang masuk.
5. **Import**: 1 transaksi, satu gagal = nol yang masuk. Semua masuk Request, urutan = urutan di file, di bawah Request
   yang udah ada. Tiap task 1 baris history Request atas nama pembuat. Pembuat baru dibikin role marketing, active;
   yang udah ada gak diubah.
6. Maks 1 MB per file.
7. `npm run check` dan `npm run build` tetap lulus.
