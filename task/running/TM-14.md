# TM-14 — Role baru QA: cuma QA + admin yang boleh geser Ready to test → Done

**Type**: feature
**Status**: Running
**Source**: perintah Iyan lewat DM, 2026-10-01
**Butuh**: TM-3 (role), TM-6 (transisi status), TM-7 (kelola users)

## Yang dibikin

Sekarang role ada 3 (`marketing`, `developer`, `admin`) dan semua aturan pindah status cuma dicek lewat `canAdvance` (= "bukan marketing") di `src/lib/roles.ts` + `checkTransition` di `src/lib/tasks.ts`. Belum ada aturan per transisi. Tiket ini nambah role `qa` dan aturan khusus buat langkah terakhir:

- **Role baru `qa`**: enum `UserRole` di schema (migration `ALTER TYPE ... ADD VALUE 'qa'`), `Role`/`roles` di `src/lib/roles.ts`, otomatis muncul di dropdown role halaman `/users`.
- **Ready to test → Done**: cuma `qa` dan `admin`. Developer kehilangan akses ini.
- **Aturan per transisi** di `checkTransition` (satu tempat, server tetap hakim): tiap transisi punya daftar role yang boleh. Tombol/drag di `/board`, `/board/list/[status]`, dan detail task ngikutin aturan yang sama, jadi developer gak lihat Done sebagai target valid.

## AC

1. Admin bisa set user jadi `qa` di `/users`.
2. QA bisa geser task dari Ready to test ke Done (drag di board dan tombol di detail).
3. Developer gak bisa geser Ready to test → Done: kolom Done gak nyala pas drag, tombolnya gak muncul di detail, dan kalau dipaksa lewat request langsung, server nolak dengan pesan jelas.
4. Admin tetap bisa semua transisi.
5. Transisi lain yang sekarang boleh buat developer tetap jalan kayak sebelumnya.
6. `npm run check` dan `npm run build` tetap lulus.

Verifikasi manual (ikutin keputusan v1 TM-9: nol test otomatis, kecuali diputusin lain pas ngerjain).
