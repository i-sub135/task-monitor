# TM-23 — Komentar di dalam task

**Type**: feature
**Status**: Backlog
**Source**: perintah Iyan lewat DM, 2026-10-07 ("fitur command di dalam task")
**Butuh**: TM-5 (halaman detail), TM-17 (API, kalau kuli ikut komentar)

## Yang dibikin

Diskusi soal task bisa ditulis langsung di halaman detail task, bukan cuma lewat catatan pas pindah status.
Asumsi: "command" = **comment** (komentar). Kalau maksudnya lain, tiket ini ditulis ulang.

## AC (draf, final setelah "Belum diputusin" dijawab)

1. Di halaman detail ada bagian **Comments**: daftar komentar (nama, waktu, isi) + kotak tulis komentar baru.
2. Komentar tersimpan per task, urut dari yang lama ke yang baru.
3. Server yang ngecek hak (bukan cuma UI ngumpetin form).
4. `npm run check` dan `npm run build` tetap lulus.

## Belum diputusin

0. **Bener "comment"?** (bukan semacam perintah/slash command)
1. **Siapa yang boleh komentar?** Semua user yang login (termasuk marketing), atau ada batasan role?
2. **Status mana aja?** Semua status termasuk Done/Live/Rejected, atau dikunci di status tertentu?
3. **Edit/hapus komentar?** Gak bisa sama sekali, cuma punya sendiri, atau admin juga bisa? Kalau hapus, diumpetin
   (kayak lampiran TM-22) atau beneran dibuang?
4. **Format isi:** teks biasa (link otomatis bisa diklik, kayak catatan di Status history) atau rich text kayak
   description?
5. **Lampiran di komentar?** Atau cukup lewat Attachments task (TM-22)?
6. **Letaknya di mana?** Di bawah description/attachments (kolom kiri), atau di kolom kanan bareng history?
7. **Di kartu board** perlu ada jumlah komentar (kayak 📎), atau gak usah?
8. **API `/api/v1`** ikut: kuli bisa baca + kirim komentar?
