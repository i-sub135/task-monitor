# TM-15 — Status Live (done-live) di kolom Done, stempel "LIVE" biru

**Type**: feature
**Status**: Ready
**Source**: perintah Iyan lewat DM, 2026-10-01
**Butuh**: TM-5 (board), TM-6 (transisi + history), TM-13 (kolom dibatasi 5 + list)

## Yang dibikin

Sekarang Done itu satu status final. Tiket ini misahin "udah kelar" sama "udah live di produksi", tampilannya **stempel "LIVE" biru** di kartu (ide Iyan).

Desain yang disepakati (Iyan, 2026-10-01 11:06):

- **Status ke-7 `done-live`** di enum `TaskStatus` (migration `ALTER TYPE ... ADD VALUE`), tapi **board tetap 6 kolom**: kolom Done isinya task `done` + `done-live` bareng. Status beda di data, kolom sama di tampilan.
- **Done → Live** (mark live) dan **Live → Done** (unmark, buat salah tandai / rollback deploy) adalah transisi biasa, otomatis tercatat di `task_history` lewat mekanisme yang udah ada. Live → Done jadi satu-satunya transisi mundur.
- **Catatan** pas mark/unmark live: opsional (mis. versi/tag rilis, link deploy).
- **Siapa**: mark live cuma developer. Pakai aturan per-transisi dari TM-14.
- **Tampilan**: kartu `done-live` dapet stempel "LIVE" (teks kapital tebal, border dobel, agak miring di pojok kanan atas, biru `#2D7495`, semi transparan biar judul tetap kebaca) di `/board`, `/board/list/done`, dan detail task. Detail task nunjukin "Live sejak <tanggal>" dari history.
- **Urutan kolom Done**: yang belum live di atas, yang live di bawah (di dalam masing-masing kelompok tetap paling baru diubah duluan). Batas 5 kartu dari TM-13 ikut urutan ini.
- `/board/list/done` nampilin `done` + `done-live`; angka di header kolom Done ngitung dua-duanya.

## AC

1. Developer bisa mark live task Done (drag/tombol), tercatat di history dengan catatan opsional.
2. Role selain developer gak bisa mark live; dipaksa lewat request langsung ditolak server dengan pesan jelas.
3. Task `done-live` bisa di-unmark balik ke Done, tercatat di history.
4. Kartu `done-live` nampilin stempel "LIVE" biru di `/board`, `/board/list/done`, dan detail task; task `done` tampil kayak sekarang.
5. Kolom Done di `/board` dan `/board/list/done`: belum-live di atas, live di bawah; angka header ngitung keduanya.
6. Task Done lama tetap kebaca normal (status `done`, belum live), nol migrasi data paksa.
7. `npm run check` dan `npm run build` tetap lulus.

Verifikasi manual (ikutin keputusan v1 TM-9: nol test otomatis, kecuali diputusin lain pas ngerjain).
