# TM-16 — Filter di /board

**Type**: feature
**Status**: Backlog
**Source**: perintah Iyan lewat DM, 2026-10-02
**Butuh**: TM-13 (batas 5 kartu + /board/list/[status]), TM-12 (platform)

## Yang dibikin

`/board` sekarang nampilin semua task tanpa saringan. Tiket ini nambah baris filter di atas board biar
bisa nyaring kartu, mis. cuma bug, cuma platform Mobile, atau cuma task yang dibikin orang tertentu.

Draft (detail nunggu keputusan di bawah):

- Baris filter di atas kolom: **Type** (bug/feature), **Platform** (api/mobile/ai-chat/web/other),
  **Pembuat** (user), **Cari judul** (teks).
- Filter disimpen di query URL (mis. `/board?type=bug&platform=mobile`), jadi bisa di-refresh,
  di-bookmark, dan dibagi linknya.
- Filter berlaku sebelum batas 5 kartu: 5 kartu yang tampil = 5 teratas dari hasil filter, badge jumlah
  di header kolom = jumlah hasil filter.
- Tombol "Reset" buat hapus semua filter.

## AC

1. Tanpa filter, `/board` sama persis kayak sekarang.
2. Pilih filter → tiap kolom cuma nampilin task yang cocok, jumlah di header ikut hasil filter, "Read more"
   muncul kalau hasil filter di kolom itu >5.
3. Filter kebawa di URL; refresh / buka link yang sama → filter yang sama aktif.
4. Reset → balik ke tampilan tanpa filter.
5. `npm run check` dan `npm run build` tetap lulus.

Verifikasi manual (ikutin keputusan v1 TM-9: nol test otomatis).

## Belum diputusin

1. **Filter apa aja?** Draft: type, platform, pembuat, cari judul. Ada yang dibuang / ditambah?
2. **Satu nilai atau banyak per filter?** Mis. platform bisa pilih Mobile + Web sekaligus (chip
   multi-pilih kayak di form new task), atau cuma satu (dropdown)?
3. **Ikut ke `/board/list/[status]`?** Usul: iya, link "Read more" bawa filter yang sama, dan halaman
   list punya baris filter juga.
4. **Reorder pas filter aktif.** Posisi (#1, #2, …) itu urutan satu kolom penuh; kalau sebagian kartu
   ketutup filter, ▲▼ bakal "lompatin" kartu yang gak keliatan dan bikin bingung. Usul: ▲▼ dan drag
   reorder dimatiin selama filter aktif; drag pindah status tetap jalan.
