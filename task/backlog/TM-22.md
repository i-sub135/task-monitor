# TM-22 — Edit lampiran task sampai sebelum Done

**Type**: feature
**Status**: Backlog
**Source**: perintah Iyan lewat DM, 2026-10-07 ("attachment masih bisa di edit sampe sebelum done")
**Butuh**: TM-4 (upload lampiran), TM-9 (driver `s3`), TM-11 (edit history)

## Yang dibikin

Sekarang lampiran cuma bisa diupload pas bikin task; di halaman detail cuma bisa dilihat. Tiket ini bikin lampiran
bisa diubah dari halaman detail selama task **belum Done**.

Beda sama title/description/type (TM-11) yang cuma bisa diedit di Request/Queue: lampiran jendelanya lebih
lebar, sampai sebelum Done.

## AC

1. Di halaman detail, task di Request / Queue / In progress / Ready to test bisa **nambah** dan **hapus** lampiran.
   Aturan ukuran/jenis file sama kayak form New task. Jumlah lampiran di detail **gak dibatasi** (batas 5 cuma
   berlaku pas create).
2. Done, Live, Rejected: lampiran read-only.
3. Hapus = **diumpetin** dari task, file-nya tetep disimpen di storage (lokal/Wasabi).
4. Tiap tambah/hapus kecatet di Edit history, plus link ke file-nya (dibuka di tab baru). File yang udah dihapus
   tetep bisa dibuka dari link di history.
5. Semua user yang login boleh.
6. API `/api/v1` ikut dapet tambah/hapus lampiran (aturan sama kayak UI).
7. Server yang ngecek status (bukan cuma UI ngumpetin tombol).
8. `npm run check` dan `npm run build` tetap lulus.
