# TM-22 — Edit lampiran task sampai sebelum Done

**Type**: feature
**Status**: Backlog
**Source**: perintah Iyan lewat DM, 2026-10-07 ("attachment masih bisa di edit sampe sebelum done")
**Butuh**: TM-4 (upload lampiran), TM-9 (driver `s3`), TM-11 (edit history)

## Yang dibikin

Sekarang lampiran cuma bisa diupload pas bikin task; di halaman detail cuma bisa dilihat. Tiket ini bikin lampiran
bisa diubah dari halaman detail selama task **belum Done**.

Beda sama title/description/type (TM-11) yang cuma bisa diedit di Request/Queue: lampiran jendelanya lebih
lebar, sampai sebelum Done.

## AC

1. Di halaman detail, task yang belum Done bisa nambah lampiran (aturan ukuran/jenis file sama kayak form New task,
   total tetep maks 5 per task).
2. Begitu task Done/Live, lampiran balik read-only.
3. Tiap perubahan lampiran kecatet di Edit history.
4. Server yang ngecek status (bukan cuma UI ngumpetin tombol).
5. `npm run check` dan `npm run build` tetap lulus.

## Belum diputusin

1. **"Sebelum Done" itu status mana aja?** Usul: Request, Queue, In progress, Ready to test. Rejected gimana, ikut
   read-only (udah ada Recreate) atau masih bisa?
2. **Edit = nambah aja, atau nambah + hapus?**
3. **Kalau hapus:** file beneran dibuang dari storage (lokal/Wasabi), atau cuma diumpetin dari task tapi file-nya
   masih disimpen?
4. **Siapa yang boleh?** Semua user yang login (sama kayak edit title sekarang), atau cuma pembuat task + developer
   ke atas?
5. **API `/api/v1`** ikut dapet upload/hapus lampiran, atau UI aja dulu?
