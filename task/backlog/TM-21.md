# TM-21 — Recreate task yang udah di-reject

**Type**: feature
**Status**: Backlog
**Source**: perintah Iyan lewat DM, 2026-10-07 ("task yg udah di reject itu ada fitur recreate")
**Butuh**: TM-4 (form New task), TM-6 (reject), TM-11 (edit history)

## Yang dibikin

Task Rejected bisa diajuin ulang tanpa ngetik dari nol. Task lama tetep apa adanya (Rejected, gak diubah).

Alur:
1. Di task yang statusnya **Rejected**, ada tombol **Recreate**.
2. Klik → buka **New task** yang udah keisi dari task lama (title, description, type, platform). Semua bisa diubah.
3. Submit → jadi task **baru** di Request (aturan sama kayak bikin task biasa).
4. Di **Edit history** task baru ada entri "Recreated from <judul task lama>" + link ke task lama.
5. Habis submit, redirect ke detail task baru.

## AC

1. Tombol Recreate cuma muncul di task Rejected.
2. Form New task keisi dari task lama, bisa diubah sebelum submit.
3. Task baru masuk Request; task lama gak berubah sama sekali.
4. Edit history task baru nunjukin asal recreate + link yang bisa diklik ke task lama.
5. `npm run check` dan `npm run build` tetap lulus.

## Belum diputusin

1. **Tombol di mana:** cuma di halaman detail task Rejected, atau juga di kartu kolom Rejected?
2. **Lampiran task lama:** ikut disalin ke task baru, atau gak ikut (upload ulang kalau perlu)?
3. **Pembuat task baru:** orang yang klik Recreate, atau tetep pembuat task lama?
4. **Penanda di task lama:** task lama tetep Rejected & gak diubah, tapi boleh ada info read-only
   "Recreated as → <task baru>" di detailnya? Atau bener-bener gak ada tambahan apa pun?
5. **Berapa kali:** satu task Rejected boleh di-recreate berkali-kali, atau sekali aja?
6. **Siapa yang boleh:** semua user yang login (sama kayak bikin task), atau ada batasan role?
