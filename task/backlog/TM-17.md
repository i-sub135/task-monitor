# TM-17 — API token per user + API kirim/update task

**Type**: feature
**Status**: Backlog
**Source**: brainstorming Iyan lewat DM, 2026-10-05
**Butuh**: TM-6 (transisi), TM-11/TM-12 (edit task), TM-14 (aturan role)

## Yang dibikin

User punya token. Token dipakai kuli atau user itu sendiri buat hit API: kirim task baru dan update task.

**Token**
- Maks **5 token aktif** per user. Penuh → revoke salah satu dulu (revoke + generate = refresh).
- Token = user pemiliknya. Hak persis sama kayak user itu di UI (role + aturan transisi yang udah ada), gak ada aturan khusus.
- Tiap token dikasih nama (mis. "Kuli Coding"). Nama ini ikut kecatet di history: "Iyan Subdiana via Kuli Coding".
- Token cuma ditampilin sekali pas generate. DB nyimpen hash-nya doang.

**Halaman token**
- Klik logo user di navbar → halaman daftar token (`/account/tokens`). Cuma buat **developer, QA, admin**; marketing (paling bawah) gak dapet link-nya dan gak bisa generate.
- Isi: daftar token (nama, awalan token, dibikin kapan, terakhir dipakai) + tombol Revoke, form generate (nama doang).

**API** (`Authorization: Bearer <token>`, flow sama persis kayak UI)
- `POST /api/v1/tasks` — kirim task baru (title, description, type, platform), masuk Request.
- `GET /api/v1/tasks/:id` — baca task, termasuk `updated_at`.
- `PATCH /api/v1/tasks/:id` — edit title/description/type/platform (tetep cuma pas Request/Queue).
- `POST /api/v1/tasks/:id/transition` — geser status (`to`, `note`).
- Update wajib GET dulu: PATCH/transition wajib bawa `expected_updated_at` dari GET. Gak bawa → ditolak; beda (task udah diubah sejak dibaca) → ditolak, suruh GET ulang.

## AC

1. Developer/admin bisa generate token dari halaman token, token muncul sekali; token ke-6 ditolak sampai ada yang di-revoke.
2. Token yang di-revoke langsung gak bisa dipakai.
3. API create/edit/transition jalan dengan hak yang sama kayak user itu di UI (yang ditolak di UI juga ditolak di API).
4. Update tanpa `expected_updated_at` atau dengan nilai basi ditolak.
5. History/edit history nunjukin nama token yang dipakai.
6. `npm run check` dan `npm run build` tetap lulus.
