# TM-13 — Batasi kartu per kolom di /board, "read more" ke halaman list per status

**Type**: feature
**Status**: Ready
**Source**: perintah Iyan lewat DM, 2026-09-28
**Butuh**: TM-5 (papan board yang ada sekarang)

## Yang dibikin

`/board` sekarang nampilin semua task di tiap kolom tanpa batas — makin lama makin panjang. Tiket ini batesin tampilan jadi maks **5 kartu per kolom**, sisanya diakses lewat link "read more" ke halaman list khusus satu status:

- **`/board`**: tiap kolom (Request, Queue, In progress, Ready to test, Done, Rejected) cuma nampilin 5 kartu teratas (urutan sama kayak sekarang — `ordering` buat Request/Queue, `updatedAt` desc buat kolom lain). Kalau kolom itu isinya lebih dari 5, muncul link "read more" di bawah kartu ke-5.
- **Route baru `/board/list/[status]`**: nampilin SEMUA task di status itu doang (nol batas 5), pake slug `Status` yang sama kayak dipake di tempat lain (`request`, `queue`, `in-progress`, `ready-to-test`, `done`, `rejected`).
- **`listBoard`** (`src/lib/server/tasks.ts`) disentuh buat propagate total count per kolom (biar UI bisa nunjukin "lihat semua (12)" atau semacamnya) dan/atau versi khusus buat satu status.

## AC

1. `/board`: kolom yang isinya ≤5 task tampil normal, nol perubahan (nol "read more" muncul).
2. `/board`: kolom yang isinya >5 task cuma nampilin 5 kartu + link "read more" yang bawa ke `/board/list/<status>`.
3. `/board/list/<status>`: nampilin semua task status itu, urutan sama kayak kolom aslinya.
4. `npm run check` dan `npm run build` tetap lulus.

Verifikasi manual (ikutin keputusan v1 TM-9: nol test otomatis, kecuali diputusin lain pas ngerjain).

## Belum diputusin

- **Drag-and-drop di `/board/list/[status]`**: halaman list ini cuma buat liat/scroll (read-only), atau tetep bisa drag-reorder/pindah status kayak kolom di `/board` (Request/Queue yang emang bisa di-reorder)? Kalau bisa, butuh mirror interaksi drag yang udah ada; kalau read-only, lebih sederhana tapi user harus balik ke `/board` buat reorder.
- **Nomor total di kolom**: header kolom di `/board` nunjukin jumlah total task (mis. "Request (12)"), atau tetep polos kayak sekarang dan "read more"-nya aja yang nunjukin sisanya?
- **Kartu ke-6 dst pas drag masuk kolom penuh**: kalau kolom udah nampilin 5 dan ada kartu baru masuk (drag dari kolom lain, atau task baru dibikin), kartu itu tetep masuk hitungan 5 teratas (kartu ke-5 lama kegeser ke "hidden", cuma keliatan di `/board/list`) — ini default assumption, tinggal bilang kalau maksudnya beda.
- **Kolom tanpa ordering** (In progress/Ready to test/Done/Rejected, sort by `updatedAt` desc): 5 teratas otomatis berarti "5 yang paling baru diubah". Ini match ekspektasi Iyan?
